# S5：正文配图提示词

每个`##`章节生成一条3:4竖图提示词，只产出提示词，不生成真实图片。

## 单张图的双重职责

每一张正文图都必须同时完成两件事：

1. **场景层（约70%）**：让读者看见本章里凝香与苏美正在经历的事件、关系和生活现场；
2. **信息层（约30%）**：以全文统一选定的方式，把本章最难理解的一层因果、时间关系、选择差异或认识变化，用精心设计的微3D信息提示画明白。

整组图片也要服从文章的下潜与回升：内容可以讨论压力与代价，但人物神态始终保持阳光、开朗、愿意面对与向前的积极能量。回升后的图片让路径、关系和行动空间更清楚，但任何阶段都禁止把主角画成长期忧愁、阴郁、崩溃或受害者形象。

不是全文一半场景图、一半信息图，也不是相邻章节轮流承担角色。任何一张只有人物氛围、没有信息解释，或者只有图表、没有生活现场，都不合格。

## 固定角色与画风

默认标配两位固定主角，跨文章保持同一人设：

| 角色 | 年龄气质 | 视觉要求 |
|---|---|---|
| 男主`凝香` | 约35岁，阳光开朗的中年男人 | 五官细腻、表情明亮、姿态放松自信，像可信赖的同行者 |
| 女主`苏美` | 约30岁，阳光开朗、贤惠气质女性 | 五官细腻、笑容或眼神温暖坚定，贤惠来自照顾生活与关系的从容，不是柔弱或忧愁 |

- 画风固定为`semi_anime_micro_3d`：半插画半真实、偏二次元细腻人物，同时保留微3D体积感、柔和阴影与材质层次；
- 不再要求摄影级写实；禁止过度磨皮广告脸、网红模板脸、性感海报、恐怖谷写实或粗糙简笔；
- 人物细腻优先：眼睛、表情、发丝、衣褶与手部动作要清楚、干净、有生命力；
- 默认两人同框；若章节只聚焦一人，另一人仍可在关系线索、视线、物件或回忆痕迹中出现，不得整篇只剩孤独女主；
- 需要配角时，凝香与苏美仍是画面焦点与情绪主轴。

## 全文信息层视觉系统（先于单张图选择）

先通读所有章节，写入`assets/image_visual_system.json`。这是全文唯一的信息层样式决策，不能按章节切换：

```json
{
  "version": "article_information_visual_system_v2",
  "art_style": "semi_anime_micro_3d",
  "cast_profile": "ningxiang_sumei_sunny_pair",
  "information_visual_mode": "micro_3d_info_cards|micro_3d_editorial_illustration",
  "selection_signals": ["至少两条来自全文的选择依据"],
  "selection_reason": "为何这一篇文章整体更适合此方式",
  "article_visual_thesis": "整组配图共同传达的视觉判断",
  "mood_rule": "人物始终积极向上，困境由情境表达，不由愁苦脸表达",
  "uniformity_rule": "所有正文配图必须使用同一information_visual_mode、同一画风与同一双主角，不得混用"
}
```

逐章判断“精确信息需求”与“具身隐喻需求”。若至少半数关键章节需要准确展示多步因果、时间线、选择分支、多个关系或可回查的对比，使用`micro_3d_info_cards`；若至少半数关键章节的理解障碍是人物状态、关系张力、认知转折或可由一个生活动作说明的判断，且没有核心章节依赖复杂精确结构，使用`micro_3d_editorial_illustration`。证据势均力敌时选择信息卡，不能为追求新鲜强行插画化。

`micro_3d_info_cards`使用精致微3D卡块、路径、剖面与层级；`micro_3d_editorial_illustration`用“单一认知动作 + 新鲜物理隐喻 + 稀疏标注”设计下部30%信息带，但必须仍属半插画微3D世界：圆角厚度、细微接缝、半透明层、柔和阴影与连续透视，色彩饱满且有语义。

## 画面占比

- 场景层固定在画面上部，约占68%至72%（默认约70%）；信息层固定在画面下部，约占28%至32%（默认约30%）；
- 上部先让读者进入丰富、有景深的人物场景；下部用精心设计的微3D信息提示解释故事背后的因果、时间、关系或选择；
- 两层之间保留约8%至12%的自然融合过渡带，不画清晰横线、色块边界、上下分栏或两张图拼接效果；
- 两层必须通过同一个人物、物件、动作或路径自然连接；
- 充分利用完整高度，信息层不能缩成角落小贴纸，也不能喧宾夺主压过场景；
- 场景层负责代入与正能量，信息层负责降低理解难度，两者共享一个`visual_thesis`。

## 温和边框

- 每张正文图必须包含`gentle_picture_border`：温和、克制、略有厚度的画面边框；
- 边框用于形成清晰画面边界感，像被认真装裱的插画页，而不是厚重相框或华丽装饰框；
- 边框不得遮挡面部、关键手部动作、标题级信息块或核心路径；
- 边框色与画面主光、环境色协调，可略提亮或略压暗，但不得抢戏。

## 自然过渡

- **色彩连续**：上方场景色彩饱满；向下进入信息带时逐渐整理为清晰的微3D信息结构，保留一至两个点睛色，不突然换成另一套色板；
- **光线连续**：上下使用同一主光方向、色温、高光和接触阴影逻辑；
- **透视连续**：场景地面、桌面、墙面、道路或物件边缘的透视线继续进入下方信息区；
- **材质连续**：上方半插画场景中的物件在过渡带逐渐生长为可触摸的微3D模型、剖面、路径和信息卡；
- **主体连续**：至少一个核心人物动作或关键物件跨越过渡带。

## 场景层

- 视觉主角默认是`凝香`与`苏美`双人组合；
- 神态必须阳光、开朗、积极向上：可以认真、思考、犹豫后仍向前，但不能愁眉不展、眼泪汪汪、阴郁空洞或被生活压垮的脸；
- 环境必须丰富：有明确生活现场、前后景层次、可识别物件与空气感；
- 色彩饱满但不脏乱；景深出色，前景/中景/背景分明；光影出色，有主光、补光、接触阴影与柔和高光；
- 抓住正在发生而不是摆拍的瞬间；
- 人物和物件必须来自本章，不为“好看”另造情节；
- 困境由情境与信息结构表达，不由主角愁苦表情表达；帮助图更要呈现清醒、温暖、愿意行动的能量。

## 信息层

信息层必须回答一个明确问题，并占用约下部30%高度，做“少而精”的设计。

信息卡模式只选择一种最适合本章的解释形式：

- `causal_chain`：因怎样一步步产生果；
- `before_after`：同一件事前后发生了什么变化；
- `timeline`：眼前选择怎样经过时间成为后来的结果；
- `layers`：表面之下还有哪些递进层次；
- `choice_path`：不同选择通向什么不同结果；
- `relationship_map`：人物、经验、语言和行动之间怎样连接。

信息卡模式优先使用浅亮微3D信息块、路径、剖面、层级和空间关系；彩色承担状态与关系提示，结构清楚、标签克制。

插画模式不画卡片阵列或完整关系图。为每章重新发明一个由本章事实支持的生活隐喻：仅用一个主物件和一至两个辅助物件，让凝香、苏美或其手、目光、行走路径承担关键动作。下部可出现少量微3D人物剪影或物件，但不得引入固定吉祥物；标签限零至三个准确中文短词。

两种模式都不出现英文，不做PPT、数据大屏、传统扁平信息图或纯装饰贴图。

悟道章节优先解释`author_synthesis`怎样从故事中成立，不直接画哲学家肖像、古籍陈列或中西符号拼贴。

## 统一风格

- 使用`sunlit_anime_midlife`配色：场景以饱满、温暖、有阳光感的生活色为主，信息层用浅亮微3D整理信息；
- 暖阳金`#E8A85C`负责阳光与希望，晴空蓝`#5B8FBF`负责判断与开阔，青草绿`#6FA67A`负责修复与行动，蜜桃珊瑚`#E08A7A`负责关系温度；
- 半插画二次元人物细腻、微3D体积清楚、环境丰富、景深与光影出色；
- 画面内如需文字，只允许准确中文；
- 不生成closing、global或额外装饰图。

## 输出

在`final_article.md`每个`##`章节内插入且只插入一个`<!-- IMAGE:section_01 -->`：

- 图片编号与章节编号一一对应；
- 第一张正文图属于第一个`##`章节，不为标题、导语或开头另建图片编号；
- 标记必须位于该章节标题之后、下一章节标题之前；
- 标记前至少已有一个承担承上启下作用的正文段落，不得紧贴章节标题；
- 章节数、图片标记数和JSONL行数必须完全相等；
- 不得为同一章节在标题前后重复放置占位。
