# S4：成文与HTML

完整读取`author.md`、因果主链、因果审计、前哲学人生命题、Spark定论、`wisdom_synthesis`、实际采用的哲学材料和致用设计。

## 文章认知重量

- 见事约一成半：保留进入问题不可缺少的现场；
- 究理约四成半：沿因果主链持续向下；
- 悟道约两成：哲学照亮最低点；
- 致用约两成：把读者带回现实。

比例用于内部判断，不写成栏目，也不机械计数。

## 情绪与认知曲线

文章允许并且需要沉重。中前段要让读者真实感受到时间、责任、关系、收入、身体或选择的重量，但沉重只能由生活事实和因果下潜产生，不能靠恐吓、羞辱和虚构最坏结局制造。

全文必须完成一条清楚的曲线：

> 被看见 → 现实逐层收紧 → 抵达无法回避的最低点 → 判断被重新组织 → 找到仍可改变的支点 → 带着依据回到生活

- 最低点之前不要急着安慰，也不要每揭开一层困难就立即补一句乐观口号；
- 最低点必须足够深，让读者看见问题为何长期反复，以及真正失去的可能是什么；
- `REBOUND`以后不能只做情绪抚慰，要兑现`help_contract`、`practice_design`和`anti_anxiety_audit`；
- 回升不是宣布环境会变好，而是帮助读者分清可控与不可控，恢复一种判断、能力、关系或生活秩序；
- 最终信心必须比开头更清醒：读者知道困难仍在，也知道自己下一步能做什么、怎样观察变化。

## 两遍成文

第一遍只沿真实故事、因果主链、哲学照明和现实回升把文章写完整。先让人物行动、关系变化、犹豫、代价和理解自然发生，不在每句话落笔时同时执行一长串语言禁令。

完整初稿写完后，必须从头独立精修一次：

1. **说话位置**：每个现场、原话、心理和“后来才懂”都能回到`narrative_position`与真实材料；无法证明的细节删除或改回明确的作者推测。
2. **段落推进**：给每段确认一个主要作用。后一段必须增加动作、关系变化、因果、代价、判断或现实支点；只把前文换一种说法时合并或删除。
3. **人先出现**：抽象名词连续出现时，改回谁做了什么、影响了谁、时间和责任落在哪里。动作已经让情绪成立时，少追一句解释。
4. **修辞姿势**：识别反复使用的先制造误解再翻案、整齐排比、连续设问、拟人化抽象抒情和固定短句收尾。判断直接说，依据放在附近；真正由经历推动的自我修正可以保留。
5. **朗读节奏**：连续短句像鼓点时合并，长句同时承担场景、因果和结论时拆开；段落允许长短不齐，不按固定间隔制造金句。
6. **哲学与结尾**：哲学删掉后故事仍能独立成立，哲学加入后确实增加一层理解。分别试删最后两段，删掉后回升与责任仍完整时让文章提前结束。

这次精修由LLM结合全文完成，不建立固定中文禁词表，不让脚本评价文艺感、洞察或人格。

## 结构

默认五个`##`章节，可根据故事自然收束为四至六个。章节名称来自本篇生活，不使用“见事、究理、悟道、致用”和“第X章”。因果主链仍保持五至七层，但相邻层可以在同一章节内连续下潜，不为每一层机械新建章节。

章节不是装材料的栏目，而是读者继续下潜的路标：

- 章节标题本身先交付一个清楚判断，读者只扫标题也能看见文章如何一层层深入；
- 不使用“事情的背后”“回头再看”“一些思考”这类只标方向、不提供认识的空标题；
- 标题要承接上一章留下的问题，同时点亮下一章即将证明的认识；
- 各章节承担的正文重量应大致相当，最短章节不能只是过场，最后一章不能把哲学、致用和结尾全部堆在一起；
- 开头只负责把读者带进现场，不提前吃掉第一章的主要材料；结尾只做简洁收束，不承担补足篇幅。

正文顺序：

> 真实现场 → 表面解释 → 因果逐层收紧 → 最低点 → Spark判断 → 回到故事细节 → 东方哲学照明 → 西方哲学补充或留白 → 作者综合判断 → 现实回升 → 一次收束

每层第一个实质段落前放：

```markdown
<!-- DESCENT:L1:C01 -->
```

最低点之后：

```markdown
<!-- SPARK:S01 -->
必须原样出现publish_thesis
<!-- REBOUND -->
```

现实回升阶段按`wisdom_synthesis`写入：

```markdown
<!-- WISDOM:EAST:W01 -->
东方哲学照明

<!-- WISDOM:WEST:W02 -->
仅当western_decision=use时出现

<!-- AUTHOR:SYNTHESIS -->
必须原样出现author_synthesis

<!-- PRACTICE -->
自然兑现primary_help、choice_principle、first_realistic_step与验证方式
```

顺序必须是东方在前、可选西方在后、作者综合判断与现实帮助最后。施工标记只用于阶段校验，HTML必须全部移除。

每个实际进入正文的哲学视角都要完成三件事：用准确中文交代它原本关心什么，说明它怎样照亮当前故事，再说清它不能替故事证明什么。只放一个名字、一句名言或一个标记，不算完成哲学桥。

S5负责插入每章的`<!-- IMAGE:section_01 -->`。

## 表达

- 主要叙事只使用`reader_facing_expression`；
- 默认读者只有生活经验，没有心理学、医学、哲学或其它专业背景；文章不能要求他先懂一个术语才能继续；
- 人物、动作、关系和生活选择优先于理论说明；
- 外部专业资料自然消化，不做来源播报；
- 个人经历只写成个人经历；群体倾向和一般规律不得超过`claim_scope`与证据允许的范围；
- 中心判断必须与`thesis_practice_consistency`一致，不能先宣布改变不可能，再要求读者主动改变；
- 沉重感必须来自真实代价和因果压力，不使用年龄羞辱、收入羞辱、关系威胁或灾难化未来替代洞察；
- `REBOUND`后的每一部分都要逐步恢复读者的主体性，但不把困难轻描淡写；
- 主要帮助必须与`help_contract.primary_help`一致；其它帮助只能作为自然副产品，不能在结尾临时罗列；
- 原话直接使用准确中文；
- 以“一句一行”为正文主流：一个完整语义句写成一个独立Markdown段落，句与句之间保留空行；
- 多数句行在常见手机宽度上应自然落在一至两行；一个句子已经塞进多个动作、解释或转折时，应按语义重新断句，而不是只依赖句号后的机械拆分；
- 每组通常用两至四个句行完成“发生了什么 → 我当时怎么想 → 这意味着什么”的推进，再自然进入下一组；
- 只有一个动作不能拆开、一个场景需要连续呈现或一条因果必须连贯论证时，才使用中段；
- 不连续出现两个文字墙式中长段；也不连续出现四个以上只有几个字、只负责喊口号的极短句；
- 独立句行必须承担新动作、新信息、新因果、新感受或新判断，禁止把同义反复伪装成节奏；
- 全篇选择三至六处真正承担因果转折、核心判断、人生洞察或现实行动的关键语句进行高亮；数量服务于内容，文章较短时可以更少；
- 完整独立判断使用整段`**重点句**`，由渲染器形成编辑强调组件；只需突出句中核心关系时，仅包裹必要词组，由渲染器形成句内高亮；
- 高亮语句必须让读者即使快速扫读也能抓住文章的认知主线，不能选择背景介绍、过渡句、重复结论或只有情绪没有新认识的话；
- 相邻两个段落不连续高亮，同一段不叠加粗体、引用和其它强调；不用加粗密度制造虚假的重要感；
- 少量使用`>`、列表和必要的章内小标题；
- 观点可以犀利，但语言保持直白、克制而有文艺范：从本篇人物、动作、物件、声音和时间痕迹中取画面，不为显得高级另造意象；
- 哲学材料先用生活语言讲清，再出现一次必要的原典名称或可靠中文表述；不用连续名言、人物介绍和哲学史说明打断故事；
- `author_synthesis`是悟道部分真正的最高点，必须由作者语气说出，并立即通过`return_to_life`回到故事；
- 不用固定比喻贯穿全文；
- 不用技术系统、机器结构、产品机制或行业术语解释人的一生；
- 不把父母、年龄或一次经历绝对化；
- 医疗等专业判断明确属于具体情境，只采用权威材料和当事人可核对记录允许的表述；
- 不虚构诊断、恶化过程或未来治疗场景来制造恐惧。

## 低负担阅读

低负担不是把文章写浅，而是让深度顺着读者已有的生活经验自然发生：

- 开头先让读者在一个动作、关系或犹豫中认出自己，再开始解释；
- 一个段落只承担一个主要任务，不在同一段同时交代背景、引入理论、完成反转和给出建议；
- 先写发生了什么，再写为什么；先用生活语言讲清，再决定是否有必要出现一次理论名称；
- 每一层下潜都由上一层留下的自然疑问进入，不能用“接下来分析”“从另一个角度看”承担转场；
- 重要判断前要有事实或因果铺垫，判断后立即回到人和生活，避免连续抽象论述；
- 允许读者放下不必要的自责时，同一语义组内说清仍需承担的责任，不能把许可写成躺平或等待命运；
- 每一屏都应出现新的动作、信息、因果或判断，不用同义金句延长停留时间；
- 列表只用于读者确实需要并列记住或执行的内容，能用连续叙事讲清时不用列表；
- 读者无需回看前文才能理解当前句，也无需猜测代词、隐喻和抽象名词指向什么。

## 开头与结尾

开头从`reader_contract.recognition_scene`对应的具体现场、动作、原话或无法忽略的结果进入，不写导读清单。前几段只建立一次代入和一个问题，不连续介绍背景、价值、结构和阅读收益。

结尾只收束一次：落实`return_to_life`，回到开头的人、物或动作，留下一个读者已经无法轻率反驳的简单判断。结尾必须兑现`permission_to_release`与`responsibility_to_keep`，让读者感到“现实没有被粉饰，但我不是毫无办法”；不能用经典名言作为最后一句，完成现实动作后不再追加第二个金句或固定互动话术。

## 篇幅

常用目标约两千个非空白字符，通常控制在一千八百至两千四百之间，阶段校验允许的上限为两千六百。篇幅有限时优先保留真实现场、完整因果主链、一个真正贴合的东方哲学视角、作者综合判断和现实动作。

压缩顺序：

1. 删除重复背景、重复场景和换一种说法再次解释的段落；
2. 合并承担同一推进任务的章节，让多层因果在同一章连续发生；
3. 东方哲学只保留最贴合的一项，西方哲学仅在确实增加新维度时进入正文；
4. 致用只交付与主要帮助直接相连的选择原则和最小行动，不扩展成清单大全；
5. 不通过压缩完整语义句、删除因果桥或把正文改成金句瀑布来缩短文章。

字数达标不能替代因果完整。每个`causal_spine`层级都必须在正文中通过对应`DESCENT`标记兑现，不能把最深一层只留在导图里。

## HTML

先写`article/final_article.md`，再运行：

```bash
python skills/midlife-article/scripts/markdown_to_wechat_html.py --topic-dir /absolute/topic/path
```

生成唯一的`article/final_article_copy.html`：

- 正文统一15px；文章标题、章节标题、章节首段和关键认知组件建立清楚的字号层级，所有可见文字均不得超过18px；
- 普通正文由脚本按完整语义句渲染为独立句行；不得使用`<br>`硬切一个尚未说完的句子；
- 句行间保留稳定呼吸感，不连续出现文字墙，也不把短语拆成伪金句瀑布；
- 章节标题采用居中、留白充分的中年生活杂志式样式；两侧短线、中央菱形、轻量编号与标题共同构成一次视觉停顿，不使用圆形章牌，不做普通列表项；
- 句内粗体渲染为暗酒红文字与暖铜下划线；整段粗体渲染为独立重点组件，二者都不得依赖背景色；
- 每章第一个实质段落由渲染器自动形成章节导语；原稿无需为了排版添加粗体或引用；
- 内联CSS；
- 不依赖页面背景；
- 明暗模式均清楚；
- 使用与配图一致的`sunlit_anime_midlife`暖色体系，但HTML不铺整页底色：晴空蓝`#5B8FBF`负责下潜与判断，蜜桃珊瑚`#E08A7A`只提示关系张力，青草绿`#6FA67A`负责回升，暖阳金`#E8A85C`保留阳光与希望；
- `SPARK`与`REBOUND`施工标记由渲染器转化为隐性的颜色节奏；`REBOUND`同时形成一条克制的回升分隔线，标记本身不得出现在HTML；
- `SPARK`、`WISDOM`、`AUTHOR:SYNTHESIS`和`PRACTICE`之后的第一个实质段落分别形成触底判断、哲学照明、作者判断和现实行动组件；组件只改变呈现，不添加标签、解释文字或新的文章内容；
- 引用用于原话、真正值得停顿的核心判断或哲学照明，全文通常二至三处；不把普通段落批量装成引用；
- 呼吸句装饰全文最多两处，只给叙事转折或真正需要停顿的一句话，不按章节平均分配；
- Markdown分隔线`---`只在自动回升分隔线之外仍有必要时使用，全文装饰分隔线合计不超过两条；它渲染为短线与菱形组合，章节标题已有装饰时，不在其上下紧邻叠加分隔线；
- 不使用渐变、大面积色块、整页背景、厚重阴影或连续边框制造气氛；立体感来自留白、少量纵线、层级色彩和长短段落的节奏；
- 同一屏通常只出现一种强装饰组件；引用、强调句、分隔线和图片位置不得连续堆叠；
- 施工标记全部移除；
- 图片只留下明确插入位置；
- 不出现账号名称、脚注和文末来源清单。
