# 财务质量指标口径

| 指标 | 公式 / 阅读要点 | 警示信号 |
|---|---|---|
| 收入增长 | 同口径本期收入 ÷ 可比期收入 − 1 | 并购、汇率或一次性确认掩盖内生放缓 |
| 毛利率 | 毛利 ÷ 收入 | 用促销、一次性低成本库存或会计分类解释的改善 |
| 营业利润率 | 营业利润 ÷ 收入 | 研发、销售投入递延或一次性费用反转 |
| 经营现金流 | 现金流量表经营活动净额 | 利润增长而现金流持续落后 |
| 自由现金流 | 经营现金流 − 资本开支；按公司定义复核 | 把收购、融资租赁或资本化成本排除而夸大 |
| DSO | 期末应收账款 ÷ 当期收入 × 当期天数 | 增速显著高于收入，可能预示回款或渠道压力 |
| 库存周转 | 优先使用公司披露；否则说明估算假设 | 库存增长快于收入、减值或价格下行风险 |
| 净债务 | 有息债务 − 现金及高流动性投资 | 到期集中、浮息敞口、受限现金 |
| SBC 稀释 | 股票薪酬与稀释后股数趋势共同观察 | 回购不足以抵消持续稀释 |

不要跨公司机械比较口径不同的“调整后 EBITDA”“自由现金流”或分部利润。披露公式、单位、期间和重述情况。
